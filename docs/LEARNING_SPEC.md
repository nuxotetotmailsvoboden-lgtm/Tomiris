# Learning specification

Learning is not implemented in Phase 01. Future reputation updates must use delayed, versioned
labels; avoid look-ahead and survivorship bias; score by asset/horizon/regime; account for shared
sources; use minimum sample sizes and uncertainty; and never self-deploy code or relax risk limits.

Raw outcomes, label policy, model version, feature version, and evaluation window must remain
reproducible. Poor performance creates review work; an autonomous “retraining” action is not an
acceptable substitute for diagnosis.
